# Citrix Tools using Ansible for Citrix® Virtual Apps and Desktops
Citrix Tools using Ansible for Citrix® Virtual Apps and Desktops is a comprehensive set of Ansible playbooks designed to guide customers through the installation and management of various Citrix components using Ansible automation. **Please note that this module is still in Tech Preview.**

# Environment Requirement
Ansible (https://docs.ansible.com/ansible/latest/installation_guide/intro_installation.html)

# Guides
[Installing and Configuring Ansible, Terraform, and Packer for Citrix Infrastructure-as-Code-based Environments](https://community.citrix.com/tech-zone/build/deployment-guides/create-iac-vm/)
